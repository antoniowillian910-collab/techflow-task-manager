# TechFlow-Solutions

> **Autor:** Willian

Sistema web de gerenciamento de tarefas com metodologia ágil, Kanban e CI com GitHub Actions

## TechFlow Solutions: Sistema de Gerenciamento de Tarefas

## Objetivo
Sistema web para a startup de logística acompanhar o fluxo de trabalho,
priorizar tarefas críticas e monitorar o desempenho da equipe.

## Escopo inicial
- Criar, listar, editar e remover tarefas (CRUD)
- Status da tarefa: A Fazer, Em Progresso, Concluído

## Metodologia
Kanban híbrido com Scrum: quadro no GitHub Projects, entregas pequenas
e commits frequentes, cada card vinculado a uma issue.

## Como executar

Siga os passos abaixo para clonar, instalar as dependências, rodar a aplicação e executar os testes automatizados:

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/antoniowillian910-collab/techflow-task-manager.git](https://github.com/antoniowillian910-collab/techflow-task-manager.git)
   cd techflow-task-manager
- pip install -r requirements.txt
- python src/app.py
- PYTHONPATH=. pytest
  ### Por que esse conteúdo é ideal?
* Ele é direto, limpo e utiliza exatamente os comandos que você configurou e testou com sucesso no GitHub Actions.
* Ele fecha com chave de ouro a documentação do seu repositório, deixando-a com padrão profissional para a entrega final ao professor!
